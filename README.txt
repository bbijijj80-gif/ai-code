# README - Космический Шутер

## Описание игры
Космический шутер с отличной графикой, звуковыми эффектами и динамичным геймплеем.

## Особенности
- ✨ Красивый анимированный фон со звёздами
- 🎮 Плавное управление кораблём
- 🔫 Стрельба с разными режимами
- 👾 Три типа врагов с разным поведением
- 💥 Эффектные взрывы
- 🎵 Звуковые эффекты (выстрелы, взрывы, бонусы)
- ⚡ Бонусы: здоровье, скорость, скорострельность
- 📊 Система уровней и очков
- ❤️ Полоска здоровья

## Управление
- **Стрелки** - Перемещение корабля
- **Пробел** - Стрельба
- **P** - Пауза
- **R** - Рестарт (после проигрыша)
- **ESC** - Выход/Пауза

## Установка

### Для Linux
```bash
cd linux_version
chmod +x run_game.sh
./run_game.sh
```

Или вручную:
```bash
pip3 install pygame
python3 space_shooter.py
```

### Для Windows
```cmd
cd windows_version
run_game.bat
```

Или вручную:
```cmd
pip install pygame
python space_shooter.py
```

## Системные требования
- Python 3.6+
- Pygame 2.0+
- Разрешение экрана: 1200x800 или выше

## Типы врагов

1. **Истребитель (Fighter)** - Красный треугольник, средняя скорость
2. **Бомбардировщик (Bomber)** - Фиолетовый овал, медленный, много здоровья
3. **Разведчик (Scout)** - Оранжевый, быстрый, мало здоровья

## Типы бонусов

- 🟢 **Здоровье (+)** - Восстанавливает 25 единиц здоровья
- 🔵 **Скорость (S)** - Увеличивает скорость перемещения
- 🟣 **Мульти-выстрел (M)** - Увеличивает скорострельность

# Игра с Настройками для Linux

## Описание
Графическая игра с возможностью настройки параметров через встроенный интерфейс.
Игра использует файл конфигурации (аналог реестра в Windows) для хранения 10 различных настроек.

## Особенности
- **Графический интерфейс** - управление мышью и клавиатурой
- **Звук** - генерируемые звуковые эффекты (клики, очки, конец игры)
- **10 настраиваемых параметров**:
  1. Громкость звука (0-100)
  2. Громкость музыки (0-100)
  3. Сложность (1-5)
  4. Скорость игрока (1-10)
  5. Скорость врагов (1-10)
  6. Максимум врагов (1-20)
  7. Цвет игрока (RGB)
  8. Цвет фона (RGB)
  9. Показывать FPS (вкл/выкл)
  10. Полноэкранный режим (вкл/выкл)

- **Рекорд** - сохраняется автоматически и НЕ сбрасывается при запуске!
- **Папка с настройками** - создаётся в `~/.my_game/settings.json`

## Установка

### Требования
- Python 3.6+
- Pygame

### Установка зависимостей
```bash
pip3 install pygame
```

## Запуск

### Способ 1: Через скрипт
```bash
cd /workspace/game
./run.sh
```

### Способ 2: Напрямую через Python
```bash
python3 /workspace/game/main.py
```

## Управление в игре
- **Стрелки** или **WASD** - перемещение игрока
- **Мышь** - навигация по меню и настройкам

## Как играть
1. Запустите игру
2. Нажмите "ИГРАТЬ" в меню
3. Управляйте синим квадратом (игроком)
4. Избегайте падающих красных квадратов (врагов)
5. За каждого пройденного врага получаете +1 очко
6. При столкновении игра заканчивается
7. Ваш рекорд автоматически сохраняется!

## Настройки
В разделе "НАСТРОЙКИ" вы можете изменить:
- Ползунками: громкость, сложность, скорости, количество врагов
- Кликом по цвету: сменить цвет игрока или фона
- Чекбоксы: показать FPS, полный экран

**Важно:** Рекорд нельзя изменить вручную - он обновляется только когда вы побиваете свой предыдущий результат!

## Расположение файлов
- Игра: `/workspace/game/main.py`
- Настройки: `~/.my_game/settings.json` (создаётся при первом запуске)

## Примечание для Linux
Вместо реестра Windows игра использует JSON-файл в домашней директории пользователя.
Это обеспечивает кроссплатформенность и правильное хранение настроек в Linux.

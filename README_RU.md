# Космический Шутер / Space Shooter

Игра космический шутер с хорошей графикой, звуком и умным противником.

## Особенности

- 🎮 Динамичный геймплей
- 🎵 Процедурная генерация звуков и музыки
- ✨ Красивый анимированный фон со звёздами
- 🎯 20 сохраняемых параметров (включая лучший счёт)
- 🤖 Умные враги с разным поведением
- 💥 Эффекты взрывов
- ⚡ Бонусы и улучшения

## 20 сохраняемых значений

1. **best_score** - Лучший счёт
2. **total_games** - Всего сыграно игр
3. **total_enemies_destroyed** - Уничтожено врагов
4. **total_shots_fired** - Сделано выстрелов
5. **total_powerups_collected** - Собрано бонусов
6. **play_time_seconds** - Общее время игры
7. **last_played** - Дата последнего запуска
8. **player_name** - Имя игрока
9. **difficulty** - Уровень сложности
10. **sound_enabled** - Звук включён/выключен
11. **music_enabled** - Музыка включена/выключена
12. **screen_width** - Ширина экрана
13. **screen_height** - Высота экрана
14. **fullscreen** - Полноэкранный режим
15. **ship_color_r** - Цвет корабля (красный)
16. **ship_color_g** - Цвет корабля (зелёный)
17. **ship_color_b** - Цвет корабля (синий)
18. **particles_enabled** - Частицы включены/выключены
19. **show_fps** - Показывать FPS
20. **language** - Язык интерфейса

## Установка и запуск

### Windows

1. Откройте папку `windows_version`
2. Запустите `install.bat` для установки зависимостей
3. Запустите игру: `python space_shooter.py`

**Хранение данных:** Реестр Windows  
**Путь:** `HKEY_CURRENT_USER\Software\SpaceShooterGame`

### Linux

1. Откройте папку `linux_version`
2. Запустите `./install.sh` для установки зависимостей
3. Запустите игру: `python3 space_shooter.py`

**Хранение данных:** Файл конфигурации  
**Путь:** `~/.config/space_shooter/settings.json`

## Управление

- **Стрелки** или **WASD** - Перемещение корабля
- **Пробел** - Стрельба
- **ESC** - Пауза
- **R** - Рестарт (после проигрыша)

## Требования

- Python 3.8 или выше
- Библиотека pygame

## Структура проекта

```
/workspace
├── game_core.py              # Основной код игры
├── assets/                   # Ресурсы игры
├── windows_version/          # Версия для Windows
│   ├── space_shooter.py      # Игра с реестром Windows
│   └── install.bat           # Установщик
└── linux_version/            # Версия для Linux
    ├── space_shooter.py      # Игра с файловым хранилищем
    └── install.sh            # Установщик
```

## Примечания

- Значения в реестре/конфиге **не обнуляются** при каждом запуске
- Лучший счёт автоматически сохраняется
- Все 20 параметров сохраняются после каждого изменения
- Для Windows используется нативный API реестра через ctypes

# ИИ для написания кода на Python

## Описание

Это искусственный интеллект для генерации кода на языке Python с полной поддержкой русского языка.

## Возможности

- **Генерация кода** по описанию на русском языке
- **Анализ запроса** и определение типа кода (функция, класс, цикл, условие и т.д.)
- **Поиск похожих примеров** из встроенной базы знаний
- **Объяснение кода** на русском языке
- **Интерактивный режим** работы

## Установка

Для работы не требуется дополнительных библиотек, используется только стандартная библиотека Python.

```bash
python main.py
```

## Примеры использования

### В интерактивном режиме:

```
>>> Создай функцию для сложения двух чисел
>>> Напиши класс человека с именем и возрастом
>>> Как прочитать файл и обработать ошибки?
>>> Создай цикл для перебора списка
>>> Нужен код для фильтрации чётных чисел
>>> Импортируй модуль для работы с JSON
```

### Программное использование:

```python
from main import PythonCodeGenerator

generator = PythonCodeGenerator()

# Генерация кода
code = generator.generate_code("Создай функцию для вычисления факториала")
print(code)

# Объяснение кода
explanation = generator.explain_code(code)
print(explanation)

# Анализ запроса
analysis = generator.analyze_request("Напиши класс для работы с базой данных")
print(analysis)
```

## Поддерживаемые типы кода

- Функции
- Классы
- Циклы (for, while)
- Условные операторы (if/else)
- Обработка исключений (try/except)
- Списковые включения
- Импорт модулей
- Работа с файлами
- И другие конструкции Python

# Космический Шутер: Крестики в Космосе

## 📍 Где хранятся настройки

### Windows:
Настройки сохраняются в **реестр Windows**:
```
HKEY_CURRENT_USER\Software\SpaceShooterGame
```

Чтобы увидеть настройки в реестре:
1. Нажмите `Win + R`
2. Введите `regedit`
3. Перейдите в `HKEY_CURRENT_USER\Software\SpaceShooterGame`

Там будут значения:
- `high_score` - ваш рекорд (НЕ меняется при каждом запуске!)
- `volume` - громкость
- `player_speed` - скорость игрока
- `bullet_speed` - скорость пули
- `enemy_speed` - скорость врагов
- `spawn_rate` - частота появления врагов
- `show_fps` - показывать FPS
- `sound_enabled` - звук включён
- `player_color` - цвет игрока (JSON)
- `bullet_color` - цвет пули (JSON)
- `bg_color` - цвет фона (JSON)

### Linux:
Настройки сохраняются в файл:
```
~/.space_shooter/settings.json
```

## Описание
Динамичный космический шутер, где вы управляете кораблём-крестиком и сражаетесь против вражеских крестиков.

## Особенности
- 🎮 **Игрок виден** - большой яркий корабль-крестик с детализацией
- 🔊 **Звуковые эффекты** - выстрелы, взрывы, попадания (генерируются программно)
- ⚙️ **Настройки через интерфейс** - 7 параметров можно менять в игре
- 💾 **Сохранение рекорда** - ваш лучший счёт сохраняется в ~/.space_shooter/settings.json
- 🌟 **Красивая графика** - звёздный фон, эффекты, анимации

## Управление
- **Стрелки / WASD** - перемещение корабля
- **Пробел** - выстрел / старт игры
- **S** - открыть настройки (в меню)
- **ESC** - выход / назад

## Настройки (меняются в игре)
1. Громкость звука (0-100)
2. Скорость игрока (1-10)
3. Скорость пули (3-15)
4. Скорость врагов (1-8)
5. Частота появления врагов (20-120 кадров)
6. Показать FPS (вкл/выкл)
7. Звук (вкл/выкл)

## Запуск
```bash
cd /workspace/space_shooter
./run.sh
```

Или напрямую:
```bash
python3 main.py
```

## Структура
- `main.py` - основной код игры
- `run.sh` - скрипт запуска
- `README.md` - этот файл
- `~/.space_shooter/settings.json` - файл настроек (создаётся автоматически)

## Требования
- Python 3
- Pygame (устанавливается автоматически при первом запуске)

## Примечания
- Рекорд **НЕ сбрасывается** при перезапуске игры
- Все настройки кроме рекорда можно изменить через меню настроек
- Игра работает на Linux и Windows
